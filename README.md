# Basic CLI Calculator

A beginner-friendly command-line calculator built with Python.

## Features
- Personalised greeting — welcomes you by name
- Supports 6 operations: +, -, *, /, ** (power), sqrt
- Runs in a loop — keeps calculating until you type 'Done'
- Error handling — won't crash on invalid inputs or divide-by-zero
- User-friendly prompts throughout

## How to Use
1. Run the file: `python PyCalc_CLI.py`
2. Enter your name when prompted
3. Enter two numbers and choose an operation
4. Type `Done` when you're finished

## Operations
| Operation | Symbol |
|-----------|--------|
| Addition | + |
| Subtraction | - |
| Multiplication | * |
| Division | / |
| Power | ** |
| Square Root | sqrt |

## Requirements
- Python 3.x
